# Shotnix roadmap

What comes next, and what is being considered. The list is short on purpose and changes with what people ask for. Everything that already shipped is in the [changelog](CHANGELOG.md).

## Next

- **Install with Homebrew.** `brew install --cask shotnix`. Homebrew takes an app from its own developer once the repository has 225 stars, and Shotnix isn’t there yet. A star gets it closer.
- **Version 1.0.** Shotnix has been a beta since its first release. 1.0 is the release where that label comes off.

## Being considered

Nothing here is promised. What moves an item up is people asking for it: open an issue that says what you would use it for, or add a 👍 to one that exists.

- **Shortcuts and links.** Actions for the Shortcuts app and `shotnix://` links, so a screenshot or a recording can start from Shortcuts, a launcher, or a script.
- **iPhone and iPad recordings in a device frame.** Record a connected device and show it in its frame, with the same zooms, captions and export as a Mac recording.
- **More languages.** Shotnix speaks English, German, French, Simplified Chinese, Russian, Ukrainian and Japanese. Say which one you are missing.

## Follow along

- **Star the repository.** It helps other people find Shotnix, and it counts toward Homebrew.
- **Watch → Custom → Releases** to hear about each new version.
- **[Open an issue](https://github.com/OMARVII/Shotnix/issues/new)** for a bug or an idea. Requests from issues ship: per-clip sound levels, typed speeds, text styles and volume past 100% all started as one.
